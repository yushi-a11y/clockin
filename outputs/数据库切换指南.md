# 双数据库后端使用指南

## 概述

系统现在支持 Supabase 和 Firestore 双后端，可以一键切换。

## 切换数据库

在浏览器控制台运行：

```javascript
// 切换到 Firestore
switchDBProvider('firestore')
// 然后刷新页面

// 切回 Supabase
switchDBProvider('supabase')
// 然后刷新页面
```

## 配置 Firestore

### 第一步：创建 Firebase 项目

1. 访问 [Firebase Console](https://console.firebase.google.com/)
2. 点击「添加项目」
3. 输入项目名称（如 `clockin-attendance`）
4. 可以禁用 Google Analytics（不需要）
5. 创建完成后进入项目

### 第二步：创建 Firestore 数据库

1. 在左侧菜单点击「Build」→「Firestore Database」
2. 点击「创建数据库」
3. 选择「以测试模式启动」（后续可以配置安全规则）
4. 选择离你最近的服务器位置（如 `asia-east1`）

### 第三步：获取配置信息

1. 点击左上角齿轮图标 → 「项目设置」
2. 滚动到「您的应用」部分
3. 点击 Web 图标 `</>` 注册应用
4. 输入应用名称（如 `clockin-web`）
5. 复制配置信息，填入 `index.html` 中的 `FIREBASE_CONFIG`：

```javascript
const FIREBASE_CONFIG = {
  apiKey: "AIza...",           // 你的 API Key
  authDomain: "xxx.firebaseapp.com",
  projectId: "xxx",
  storageBucket: "xxx.appspot.com",
  messagingSenderId: "000000000000",
  appId: "1:000:web:abc123"
};
```

### 第四步：迁移数据

1. 确保当前是 Supabase 模式（默认）
2. 打开浏览器控制台
3. 粘贴并运行 `migrate-to-firestore.js` 中的代码
4. 运行 `migrateSupabaseToFirestore()`
5. 等待迁移完成
6. 运行 `switchDBProvider('firestore')` 切换
7. 刷新页面验证

## 回切 Supabase

如果 Firestore 效果不好：

```javascript
// 方法1：控制台运行
switchDBProvider('supabase')
// 刷新页面

// 方法2：清除 localStorage
localStorage.removeItem('db_provider')
// 刷新页面
```

数据还在 Supabase，不会丢失。

## 反向迁移（Firestore → Supabase）

如果需要把 Firestore 的数据迁回 Supabase：

1. 先切换到 Firestore 模式并刷新
2. 在控制台运行 `migrate-to-firestore.js`
3. 运行 `migrateFirestoreToSupabase()`
4. 运行 `switchDBProvider('supabase')` 切换回来

## 安全规则（生产环境）

Firestore 测试模式默认完全开放。生产环境建议配置安全规则：

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 所有集合：允许读写（公开应用）
    match /{document=**} {
      allow read, write: if true;
    }
    
    // 如果需要限制，可以按集合配置：
    // match /config/{docId} {
    //   allow read: if true;
    //   allow write: if true; // 建议添加认证
    // }
  }
}
```

## 故障排除

### Firestore 连接失败
- 检查 FIREBASE_CONFIG 是否正确
- 检查 Firestore 数据库是否已创建
- 检查浏览器控制台错误信息

### 数据不同步
- 确认已切换到正确的后端
- 检查网络连接
- 查看控制台是否有实时监听错误

### 切换后数据为空
- 需要先运行迁移脚本
- 确认源数据库有数据
